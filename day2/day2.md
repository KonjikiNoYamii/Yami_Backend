# Daily Quest

## 1. Apa itu Node.js?
Node.js adalah tempat untuk menjalankan JavaScript di luar browser.  
Biasanya dipakai untuk membuat server, API, dan backend aplikasi.


## 2. Bedanya Node.js dengan JavaScript di Browser?
-Browser dipakai untuk tampilan web (HTML, DOM).  
-Node.js dipakai untuk backend/server, bisa akses file system dan jaringan.


## 3. Apa fungsi `import`/module di Node.js?
Untuk mengambil kode dari file lain supaya program lebih rapi dan tidak menumpuk di satu file.
